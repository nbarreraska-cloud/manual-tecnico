```text
La percepción también depende de la adaptación del sistema visual a las condiciones de iluminación y al entorno cromático.
Después de observar durante cierto tiempo una fuente de luz o un campo de color determinado, la valoración de otras muestras puede cambiar. Por ello, no siempre resulta conveniente tomar decisiones definitivas después de observar una pequeña muestra de forma prolongada y aislada.
```

```text
4.3.2. El modelo RGB: mezcla aditiva
El modelo RGB se basa en la combinación de luz roja, verde y azul. Se utiliza principalmente en pantallas y sistemas de reproducción electrónica.
En este modelo, la combinación de las tres luces a intensidad máxima produce luz blanca, mientras que la ausencia de luz corresponde al negro.
Combinaciones básicas:
· Rojo + verde: amarillo.
· Verde + azul: cian.
· Azul + rojo: magenta.
```

### Fragment 3

```text
4.4. Dimensiones del color: matiz, valor y croma
Para analizar y describir el color de una superficie de forma más precisa es necesario distinguir diferentes dimensiones.
Una organización especialmente útil para la pintura es la que considera matiz, valor y croma. El sistema Munsell utiliza estas tres dimensiones para describir los colores de superficies mediante una organización tridimensional.
Esta descripción resulta útil para comparar colores, aunque no representa por sí sola todos los aspectos de la apariencia de un objeto iluminado. Los reflejos, la transparencia y otras condiciones de iluminación pueden requerir atributos adicionales.
4.4.1. Matiz
El matiz permite identificar la familia cromática a la que pertenece un color.
Es la dimensión que permite diferenciar, por ejemplo, un rojo de un azul, un amarillo de un verde o un violeta de un naranja.
```

### Fragment 4

```text
4.6. Relaciones y armonías cromáticas
Una armonía cromática es una relación organizada entre varios colores que permite construir una composición visual coherente.
Las armonías no son fórmulas que garanticen automáticamente un resultado atractivo. Son herramientas para seleccionar y organizar colores según sus relaciones dentro de un modelo cromático.
La elección final dependerá también de los valores, los cromas, la extensión de cada superficie y la función visual de los elementos.
Los esquemas siguientes se explican tomando como referencia el círculo cromático RYB tradicional. Sus relaciones no deben trasladarse automáticamente a otros modelos cromáticos.
4.6.1. Armonía monocromática
Se construye a partir de un mismo matiz o de una familia cromática muy próxima, introduciendo variaciones de valor y croma.
```

### Fragment 5

```text
4.6.7. Aplicación de las armonías a una miniatura
Para trasladar una armonía cromática a una figura es necesario decidir qué función tendrá cada color.
Una posible organización consiste en distinguir:
· Color dominante: establece la identidad cromática principal. No tiene que ser necesariamente el más intenso ni ocupar siempre la mayor superficie.
· Color secundario: complementa al dominante y diferencia superficies.
· Color de acento: introduce puntos de interés.
· Colores de transición: ayudan a integrar elementos relacionados.
```

### Fragment 6

```text
4.8. Mezcla de colores y modificación cromática
La mezcla permite modificar las características de una pintura para obtener un color diferente o ajustar uno ya existente.
En pintura de miniaturas es importante comprender que las mezclas físicas con pigmentos no se comportan exactamente igual que las combinaciones teóricas de luz ni que los colores mostrados en una pantalla.
El resultado depende de las pinturas concretas, sus pigmentos, sus formulaciones y las proporciones utilizadas.
4.8.1. Mezcla física de pigmentos
Cuando se mezclan pinturas, los pigmentos interactúan con la luz mediante procesos de absorción y reflexión.
La combinación resultante puede presentar cambios de matiz, valor y croma. No debe asumirse que mezclar dos colores produce siempre un punto intermedio limpio entre ambos. Algunas mezclas pueden resultar más apagadas, oscuras o diferentes de lo esperado.
```

### Fragment 7

```text
4.11. Errores habituales en la aplicación de la teoría del color
4.11.1. Confundir matiz, valor y croma
Un error frecuente consiste en intentar resolver cualquier problema cromático cambiando el color.
Si una superficie no destaca, puede que necesite una diferencia de valor y no un cambio de matiz. Si un color parece demasiado intenso, puede que sea necesario reducir su croma y no oscurecerlo.
Corrección: identifica primero qué dimensión del color está generando el problema.
4.11.2. Considerar absolutos los colores cálidos y fríos
La temperatura cromática es relativa. Clasificar todos los rojos como cálidos y todos los azules como fríos simplifica demasiado las relaciones reales.
```
