# Annex B. Índex de tècniques

## B.1. Finalitat i abast

Aquest annex permet localitzar les tècniques i els procediments de pintura desenvolupats al manual. La seva funció és facilitar la consulta durant el treball, identificar on s'explica cada procediment i trobar-ne les aplicacions en la representació de materials i efectes.

L'índex no substitueix les explicacions dels capítols ni en reprodueix els procediments. Tampoc no constitueix una classificació científica universal: organitza els continguts d'acord amb el criteri didàctic i editorial utilitzat en aquest manual.

Les referències indiquen el capítol i els apartats en què es desenvolupa cada tècnica o se n'explica l'aplicació. Quan un procediment apareix adaptat a materials diferents, també s'hi inclouen les referències corresponents.

## B.7. Criteris de consulta

Per localitzar un contingut, convé seguir aquests criteris:

- Si es volen aprendre les tècniques generals de preparació, aplicació, construcció cromàtica, textura o il·luminació, cal consultar els capítols 7–17.
- Si es necessita planificar, seqüenciar i avaluar el procés integral de pintura, cal consultar el capítol 18.
- Si es vol representar un material o efecte concret, cal consultar el capítol corresponent de la part III.
- Si es necessita integrar cromàticament una superfície, representar-ne l'envelliment o modificar-ne l'acabat, cal consultar els capítols 35–38.
- Si el resultat presenta un problema i cal decidir com intervenir-hi, cal consultar el capítol 39.

Una mateixa tècnica pot aparèixer en diversos capítols perquè la seva aplicació depèn del material, de l'estructura de la superfície i del resultat visual buscat. La referència principal indica on es desenvolupa el procediment; les referències d'aplicació permeten localitzar exemples específics.

Aquest índex es complementa amb l'Annex C, dedicat a la localització de receptes, i amb l'Annex D, que reuneix les mescles i formulacions del manual.

## B.8. Control editorial i límits d'ús

- Les referències s'han contrastat amb els encapçalaments vigents dels capítols 7–39; s'han corregit 28 identificadors de subsecció obsolets en set entrades de l'índex.
- L'índex localitza tècniques i aplicacions, però no substitueix els procediments complets.
- Les adaptacions a materials concrets es mantenen diferenciades de les tècniques generals.
- Les referències no impliquen que totes les aplicacions hagin estat validades experimentalment.
- Les receptes i les combinacions es localitzen a l'Annex C; les mescles i formulacions, a l'Annex D.

**Estat F5:** les 62 entrades de l'índex i totes les remissions s'han contrastat amb els encapçalaments vigents dels capítols 7–39. S'han corregit 28 identificadors obsolets en set entrades; totes les remissions finals apunten a apartats existents. Les tècniques i els àmbits es mantenen; no s'han afegit procediments ni contingut tècnic.
