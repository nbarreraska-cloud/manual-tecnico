# Annex D. Taula de mescles i formulacions

## D.1. Finalitat i abast

Aquest annex reuneix les mescles i les combinacions de pintures identificades en les propostes tècniques dels capítols 19–34.

La seva finalitat és facilitar la consulta de les relacions cromàtiques entre les pintures de l'inventari de referència, mantenint la traçabilitat amb les receptes originals.

No pretén substituir les receptes dels capítols ni reproduir totes les seves seqüències d'aplicació. Recull únicament les combinacions que aporten informació específica sobre la relació entre dues o més pintures.

Les formulacions es presenten respectant el grau de precisió del document d'origen. Quan no s'hi indiquen proporcions, no s'estableixen quantitats ni relacions numèriques per iniciativa editorial.

## D.2. Criteris d'interpretació

Per evitar confusions, es distingeixen tres tipus d'informació:

- **Mescla indicada:** el text identifica expressament una mescla de pintures o una modificació cromàtica mitjançant la combinació de colors.
- **Combinació cromàtica:** s'indiquen dues o més pintures per a una funció concreta, però no s'especifica si s'han de barrejar físicament o aplicar de manera successiva o localitzada.
- **Seqüència d'aplicació:** les pintures tenen funcions diferenciades —base, ombra, il·luminació, reflex o variació— i no s'han d'interpretar automàticament com una mescla.

Les propostes recollides en aquest annex no constitueixen resultats experimentals. No s'han realitzat proves físiques documentades que permetin establir proporcions òptimes, equivalències o resultats garantits.

Les referències comercials de les pintures es troben a l'Annex A. Per evitar duplicacions, aquesta taula utilitza exclusivament els noms comercials, sense repetir els codis Vallejo.

## D.4. Formulacions i procediments que no s'han de confondre amb mescles de pintura

Algunes receptes contenen diversos colors, però la seva funció és construir una seqüència d'aplicació. No s'han de traslladar a una taula de mescles com si fossin fórmules homogènies.

Cal mantenir especialment les distincions següents:

- **Metalls:** les bases metàl·liques, les ombres, les modificacions transparents i els reflexos han de conservar les seves funcions diferenciades. Barrejar pintures convencionals amb una base metàl·lica pot modificar-ne la resposta reflectant.
- **Vegetació:** els colors de base, profunditat, aclariment i accent poden aplicar-se en zones diferents. No tots s'han d'integrar en una única mescla.
- **Pell i teixits orgànics:** les combinacions cromàtiques són punts de partida, no formulacions universals.
- **Roques i minerals:** les combinacions pictòriques representen aparences generals i no reprodueixen necessàriament la composició mineral real.
- **Cristalls i gemmes:** les combinacions s'han d'interpretar segons la funció de cada pla i la distribució dels reflexos.
- **Òxid i pàtines:** la base metàl·lica, els productes de corrosió i les zones de metall exposat s'han de distingir.
- **Foc i energia:** les transicions cromàtiques i les aplicacions successives no equivalen necessàriament a mescles a la paleta.

Les receptes de pols, terra seca, terrenys compactats i fang del capítol 29 presenten colors per a aplicacions successives o localitzades; no especifiquen mescles físiques entre pintures. El fang es descriu com una mescla física de terra o sediments amb aigua, però no constitueix una formulació de pintures i, per això, no s'incorpora a aquesta taula.

Les cinc receptes d'energia del capítol 32 i les receptes de vidre del capítol 34 inclouen seleccions cromàtiques i procediments, però no estableixen mescles físiques ni proporcions concretes; per això no generen entrades a la taula. Les combinacions cromàtiques dels fluids orgànics no sanguinis del capítol 31 sí que s'hi inclouen, per la seva vinculació explícita amb funcions cromàtiques concretes.

## D.5. Criteris per interpretar i ampliar les formulacions

- No assignar proporcions numèriques quan el document d'origen no les proporciona.
- No considerar que dues pintures indicades en una mateixa recepta s'hagin de barrejar necessàriament a la paleta.
- Mantenir la funció original de cada pintura: base, ombra, variació, aclariment, reflex o accent.
- Diferenciar les mescles físiques de les aplicacions transparents, les superposicions i les transicions.
- No substituir pintures de l'inventari per altres de nom o aparença semblants sense justificació tècnica.
- Qualsevol proporció que s'incorpori en una actualització futura haurà de procedir d'una font tècnica identificable o d'una prova física documentada.
- Les proves futures hauran de registrar les pintures utilitzades, les quantitats, el suport, la preparació, el procediment i les condicions d'observació.
- Una formulació proposada no es convertirà en un resultat comprovat pel simple fet d'incloure-la en aquest annex.

## D.6. Síntesi de l'annex

El document mestre conté nombroses combinacions cromàtiques, però només una part es formula expressament com a mescla o modificació entre pintures. D'altres indiquen combinacions sense definir-ne el mode d'aplicació, mentre que moltes receptes es construeixen mitjançant seqüències de colors amb funcions diferenciades.

L'Annex D conserva aquestes diferències i evita atribuir proporcions o resultats que no estan documentats.

La seva funció és proporcionar una referència organitzada de les mescles i combinacions identificades, mantenint la relació amb les receptes originals i deixant oberta la possibilitat d'incorporar formulacions quantificades quan hi hagi dades suficients.
