## 6. Remissions creuades

La tanda 04 proposa remissions entre les noves figures i les figures existents dels capítols 3–7, 11, 19, 24, 34 i 36. També proposa referències internes entre les noves composicions dels capítols 14, 27, 28 i 29.

Aquestes referències són candidates de navegació, no ordres d'inserció. S'aplica el criteri editorial ja establert a F11:

- No afegir una crida local repetitiva quan la figura apareix immediatament després del contingut.
- Conservar una remissió no local quan recuperi un fonament necessari o eviti duplicar un procediment.
- No alterar el text tècnic per forçar una remissió.
- No convertir una relació temàtica en equivalència entre materials o procediments.
- Revisar cada remissió sobre el paràgraf real i el muntatge final.

## 8. Separació de versions i protecció del manual

Quan comenci la inserció gràfica:

1. Es conservarà intacta la versió mestra sense imatges.
2. Es crearà una còpia independent identificada com a versió il·lustrada.
3. Les imatges, llegendes i ajustos de maquetació s'incorporaran exclusivament a la còpia il·lustrada.
4. No se sobreescriurà ni se substituirà la versió mestra.
5. Es compararan les dues versions per verificar que el text, l'estructura i els elements no gràfics s'han conservat.
6. La còpia il·lustrada tindrà identificació de versió i traçabilitat pròpies.
